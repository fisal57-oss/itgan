# نظام إتقان المطور v2.0 | Itqan Management System

نظام متكامل لإدارة الموارد، القاعات، المسارح والفعاليات - تعليم عسير (إدارة الاتصال المؤسسي).

## 🌟 المميزات:
- **لوحة التحكم والإحصائيات**: متابعة الحجوزات والمؤشرات الحية.
- **إدارة القاعات والمسارح**: جدولة الحجوزات وحالات الإشغال.
- **التقويم التفاعلي**: عرض يومي وأسبوعي وشهري للمواعيد.
- **إدارة المعدات والعهدة**: متابعة أجهزة الصوت والعرض الذكية.
- **نموذج طلب حجز رقمي**: نموذج إلكتروني خارجي لرفع طلبات الحجز.
- **بوابة حجز مقاعد المسرح والـ QR Code**: تنظيم مقاعد الفعاليات وتوليد بطاقات الدخول الرقمية.
- **التقارير التحليلية والطباعة الرسمية**: تصدير وطباعة بطاقات وتفاصيل الفعاليات.
